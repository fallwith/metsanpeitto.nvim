# metsanpeitto palette

The palette is intentionally muted. Cream foreground on ink-blue background
is the signature; accents are woodblock pastels rather than saturated
primaries.

## Backgrounds

| Name        | Hex       | Role                                  |
|-------------|-----------|---------------------------------------|
| `bg`        | `#1d2230` | Main editor background (ink-blue)     |
| `bg_dim`    | `#181c28` | Sidebars, inactive splits             |
| `bg_float`  | `#232a3a` | Popups, floats, statusline            |
| `bg_visual` | `#2e3a52` | Visual selection                      |
| `bg_cline`  | `#232838` | Cursor line                           |
| `bg_border` | `#3a4258` | Float borders, splits                 |
| `bg_hl`     | `#2a3145` | Pmenu selection, LSP references       |

## Foregrounds

| Name       | Hex       | Role                                 |
|------------|-----------|--------------------------------------|
| `fg`       | `#f5ecd7` | Main foreground (cream, signature)   |
| `fg_dim`   | `#c9c1ad` | Parameters, delimiters, secondary    |
| `fg_muted` | `#8a8478` | Non-text, gutters, deemphasis        |
| `comment`  | `#6c7a92` | Comments (slate, italic)             |
