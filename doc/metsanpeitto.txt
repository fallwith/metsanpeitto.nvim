1. INTRODUCTION                                   *metsanpeitto-introduction*

`metsanpeitto` (Finnish for the forest's spell that hides wanderers in
familiar woods) is a Neovim colorscheme that blends the ink-blue
backgrounds of kanagawa-wave with the cream foreground of atomic, the
mossy syntax of everforest, the slate comments of juliana, and the
restraint of nordfox. The signature is cream-on-ink-blue contrast,
supported by muted, never-neon accents.

It ships four palette variants -- `tihea` (default dark), `aukea` (light),
`syksy` (autumn dark), and `sumu` (fog dark) -- which share the same
structural roles but evoke different forest moods. See
|metsanpeitto-variants| for details.

==============================================================================
2. REQUIREMENTS                                   *metsanpeitto-requirements*

  - Neovim 0.9 or newer
  - `termguicolors` enabled (the colorscheme sets this for you)
  - A 'true color' capable terminal

==============================================================================
3. INSTALLATION                                   *metsanpeitto-installation*

Using `vim.pack` (Neovim 0.12+): >lua

    vim.pack.add({ 'https://github.com/fallwith/metsanpeitto.nvim' })
<
Using `lazy.nvim`: >lua

    { 'fallwith/metsanpeitto.nvim', lazy = false, priority = 1000 }
<
Using `packer.nvim`: >lua

    use 'fallwith/metsanpeitto.nvim'
<
==============================================================================
4. USAGE                                                 *metsanpeitto-usage*

Set the colorscheme: >vim

    :colorscheme metsanpeitto
<
Or in your `init.lua`: >lua

    vim.cmd.colorscheme('metsanpeitto')
<
The bare `metsanpeitto` name resolves a variant based on `vim.o.background`:
`light` selects `aukea`, otherwise `tihea`. To pick a specific variant
directly, use its full name -- for example: >vim

    :colorscheme metsanpeitto-syksy
    :colorscheme metsanpeitto-sumu
<
You can also call the loader directly: >lua

    require('metsanpeitto').load()           -- auto-resolves variant
    require('metsanpeitto').load('sumu')     -- explicit variant
<
Access the palette table for use in other plugins: >lua

    local palette = require('metsanpeitto').palette()
    print(palette.amber) -- e.g. '#e5b86a' for tihea
<

5. VARIANTS                                           *metsanpeitto-variants*

`metsanpeitto` ships four variants. Each preserves the woodblock-pastel
identity but shifts the bg, fg, and accent palette to evoke a different
forest mood. ASCII-only variant keys are intentional; the proper Finnish
diacritics live here in the prose.

`tihea` ("tiheä", dense)                       *metsanpeitto-variant-tihea*
    Default dark. Cool ink-blue background (`#1d2230`) with cream
    foreground (`#f5ecd7`). The signature.
    Entry point: `:colorscheme metsanpeitto-tihea`

`aukea` ("aukea", clearing)                    *metsanpeitto-variant-aukea*
    Light variant. Warm parchment background (`#f4ead2`) with deep slate
    foreground. Accents pushed darker for contrast on light bg. Selected
    automatically when `vim.o.background == 'light'`.
    Entry point: `:colorscheme metsanpeitto-aukea`

`syksy` ("syksy", autumn)                      *metsanpeitto-variant-syksy*
    Warm dark variant. Brown-violet background (`#2a2425`) with honey
    cream foreground. Strings shift to autumn-leaf olive, blues
    desaturate, reds and ambers warm toward rust and ember. "Same theme,
    different season."
    Entry point: `:colorscheme metsanpeitto-syksy`

`sumu` ("sumu", fog)                            *metsanpeitto-variant-sumu*
    Desaturated dark variant. Neutral slate background (`#272c34`) with
    cooled cream foreground. Every accent loses ~20-25% saturation so
    the woodblock pastels feel diffused, like seen through morning mist.
    Designed for long daily-use sessions.
    Entry point: `:colorscheme metsanpeitto-sumu`

6. CONFIGURATION                                 *metsanpeitto-configuration*

The default variant resolution can be overridden via `setup()`: >lua

    require('metsanpeitto').setup({
      variant = 'sumu', -- 'tihea' | 'aukea' | 'syksy' | 'sumu'
    })
    vim.cmd.colorscheme('metsanpeitto')
<
With this configured, `:colorscheme metsanpeitto` will use `sumu` instead
of resolving from `vim.o.background`. Specific-variant entry points like
`:colorscheme metsanpeitto-syksy` always select that variant explicitly,
ignoring `setup` config.

If `setup()` is not called, the variant is auto-resolved from
`vim.o.background` (`light` -> `aukea`, otherwise `tihea`).

==============================================================================
7. LUALINE                                             *metsanpeitto-lualine*

A `lualine.nvim` theme is included for each variant. The bare
`metsanpeitto` theme follows whichever variant is currently active: >lua

    require('lualine').setup({
      options = { theme = 'metsanpeitto' },
    })
<
To pin lualine to a specific variant regardless of the active colorscheme: >lua

    require('lualine').setup({
      options = { theme = 'metsanpeitto-sumu' },
    })
<
==============================================================================
8. PALETTE                                             *metsanpeitto-palette*

See `palette.md` in the repository root for the full color reference,
including a side-by-side comparison of all four variants.

The currently active palette is exposed via: >lua

    local palette = require('metsanpeitto').palette()
<
A specific variant's palette can be fetched directly: >lua

    local syksy = require('metsanpeitto.palette').get('syksy')
<
